# Accessibility opportunity research — 2026-08-28

app-flow-reader — low-vision knowledge workers need repeatable routes through enterprise web apps whose keyboard and screen-reader support is incomplete.
point-and-speak-desktop — intentional, local region OCR closes the gap where legacy or remote software exposes no accessibility tree.
next-physical-step — ADHD task tools are crowded, but a single concrete re-entry action directly addresses decision paralysis without another backlog.
caption-salience — captions need user-controlled emphasis for words that matter or were uncertain, not only bigger fonts.
caption-style-checker — platforms continue to flatten enhanced subtitle semantics, creating a clear local preflight need.
color-meaning-lens — temporary semantic labels can make color-only dashboard and diff states inspectable without a global color filter.
speak-page-actions — existing voice-control stacks remain piecemeal; a small local browser grammar can target labelled actions safely.
game-text-beacon — game and canvas text still bypass assistive metadata; on-demand, gamepad-friendly local OCR is a bounded fallback.
local-caption-tape — local, exportable live captions answer both accessibility and vendor-lock-in concerns around meeting transcription.
listen-back-reader — source-anchored sentence replay helps readers retain place without rewriting their material.
haptic-braille-drills — a cautiously co-designed vibration practice tool can test a low-cost tactile-learning idea before any navigation claims.
accessible-page-capture — teams need a reproducible report from the person encountering a barrier, not only an automated scanner result.
