# Games & creative opportunity research

- parent-kid-game-jam — parents want game-making to stay fun, but need a repeatable, finishable co-making ritual.
- shared-piano-takebook — browser piano practice lacks a lightweight way to keep, annotate, and hand off takes.
- gesture-gameplay-calibrator — webcam-game experiments need local gesture reliability checks before committing to input mapping.
- clean-family-coop-room — families explicitly want remote co-op without dark patterns, data harvesting, or account overhead.
- multiplayer-update-lens — small multiplayer games need room-level fanout diagnosis, not generic server metrics.
- browser-game-replay-capsule — fragmented browser-game stacks lack a tiny deterministic reproduction artifact for bugs.
- audio-graph-sketchpad — Web Audio learners need to hear and inspect causal graph changes and timing behavior.
- raw-edit-recipe-cards — novice photographers need constrained processing drills, not a bigger history stack or preset collection.
- comic-reference-sheet-board — consistent character/panel planning needs structured references without a generative-art wrapper.
- creative-tech-demo-recorder — portfolio makers need a reliable short interaction proof rather than a generic screencast workflow.
- motion-curve-playground — expressive, non-uniform movement is easier to choose when variants are immediately comparable.
- camera-effect-postcard — private, portrait-safe browser effects avoid both social-platform lock-in and virtual-camera installation.
