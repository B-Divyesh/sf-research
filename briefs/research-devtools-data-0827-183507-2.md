# Devtools/data opportunities — 2026-08-27

- api-version-replay — version-pinned integration tests are still blocked by client and provider defaults.
- idempotency-rehearsal — duplicate and reordered webhook events remain easy to ship without a local proof harness.
- recovery-drift-sentinel — green backup jobs do not prove that a current database restore works.
- devcontainer-backend-doctor — teams need a project-specific compatibility check as macOS container backends proliferate.
- telemetry-budget-guard — standardized OTEL adoption is outpacing teams’ ability to predict telemetry cost and volume.
- log-scrub-contract — more log drains increase the need to regression-test redaction before data leaves a service.
- openapi-collection-bridge — developers actively switch API clients but collection/import semantics still strand them.
- infra-test-evidence — IaC test output needs rich portable evidence, not one-off JSON-to-JUnit scripts.
- config-rationale-guard — high-demand commented config support exposes a larger need to preserve why settings exist.
- code-path-lens — semantic search and call hierarchies still do not yield a compact reviewable path through unfamiliar code.
- automation-action-receipts — agent/automation adoption makes readable, tamper-evident action trails newly urgent.
- dev-diagnostic-packet — developer diagnostics are hard to share safely and completely across a project team.
