# Utilities research — 2026-08-27

pdf-accessibility-preflight — Accessible PDF failures are still discovered after handoff; a local, plain-language preflight closes that gap.
markdown-pdf-code-proof — Long technical Markdown still loses links and usable code blocks only at PDF delivery time.
pdf-link-map — PDF converters silently break navigation, so teams need a renderer-independent link-integrity test.
scan-reading-pack — Readers need OCR output they can trace back to scanned pages, not a disconnected text blob.
import-transform-ledger — Reusable, reviewable CSV transform recipes replace fragile spreadsheet cleanup during imports.
browser-history-export-sentinel — Browser-history migration can silently export nothing, making a completeness receipt valuable now.
android-backup-coverage — Photo backups repeatedly miss files; a destination-neutral coverage check is more useful than another sync client.
google-photos-delta-archive — Revoked Google Photos scopes leave users with repeated Takeout exports and no trustworthy incremental archive.
backup-restore-drill — Layered backup setups do not prove recoverability; small scheduled restore drills do.
cold-storage-refresh-ledger — Offline archive media needs a simple record of when it was tested and when it must be refreshed.
cloud-exit-evidence — A local sync folder is not proof of cloud-exit readiness, especially when permissions exclude data classes.
calendar-handoff-card — Missed invites and calendar fragmentation make a timezone-correct, chat-ready event handoff useful.
