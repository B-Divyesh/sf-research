# Games / creative research — 2026-08-28

loop-lab — beginners are explicitly asking for a viable first path into electronic music; looping is the smallest useful foothold.
loudness-lens — surprise-volume control remains a practical request, while existing tools are device- or app-bound.
midi-sfx-pad — game prototypers need ordinary MIDI input to become quick, original SFX rather than a middleware integration project.
abc-score-play — plain-text notation can become a fast practice loop without becoming a full score editor.
linux-kid-lab — Linux parents are looking for the next age-appropriate creative activity after GCompris.
number-motion-duet — caregivers want early math play beyond counting, with accessible shared interaction.
pixel-brief-builder — weekend child-and-adult game builds fail on scope before code; a finite asset brief is timely.
pen-display-drills — tablet input is active and beginners still need short, guided drawing practice.
flipbook-trace — creators are directly asking how to turn video into hand-drawn flipbook work without a heavyweight editor.
move-to-play-calibrator — webcam body controllers need trustworthy gesture calibration before game integration.
camera-fx-cues — playful webcam effects and event-triggered camera language are both active current requests.
led-layout-checker — large addressable-LED artists need a safer, visual preflight before wiring and buying hardware.
