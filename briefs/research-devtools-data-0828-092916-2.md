# Devtools/data research — 2026-08-28

agent-permission-map — Coding-agent permissions now span global and project files, making effective access hard to audit before a run.

worktree-secret-broker — Disposable worktrees need selected development secrets without copying `.env` files or broadening access.

incident-boundary-replay — Cross-service incidents still lack a safe, scrubbed artifact that reproduces the failing integration boundary.

log-drain-contract-check — Teams need to preflight volume, fields, and sensitive data before committing a managed log drain.

legacy-change-radar — AI-era reviews of established codebases need blast-radius context beyond a raw diff.

change-checkpoint-manifest — A rollback is more useful when the exact workspace state and validation evidence travel together.

mcp-result-envelope — MCP/CLI authors need a stable, token-bounded way to expose large structured tool results to models.

action-parity-probe — GitHub Actions alternatives need a concrete compatibility report before workflows are moved.

github-dependency-exit — Small teams need an inventory of GitHub-bound integrations before they can assess an exit or fallback.

restore-compatibility-drill — Backup ownership is not recovery readiness until a real, version-matched restore is tested regularly.

alert-config-change-ledger — Alert routing drift across UI and git remains hard to attribute before an on-call incident.

background-worktree-verifier — Multi-worktree agent workflows need fast, isolated smoke-test freshness without waiting for CI.
