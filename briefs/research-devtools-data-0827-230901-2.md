# devtools-data opportunities — 2026-08-27

- config-drift-timeline — incidents still originate in untraceable environment differences, while shared agent configuration makes drift more common.
- kube-permission-evidence — audit evidence remains manual just as Kubernetes authorization becomes more granular.
- agent-write-barrier — coding-agent filesystem access is actively requested, but git diff misses persistent execution surfaces.
- state-transition-capsule — persistent/offline state makes second-run failures hard to reproduce and explain.
- data-engine-switchboard — fast dataframe migration is compelling, but teams need parity and streaming-fallback evidence before switching.
- viewport-fact-sheet — DOM snapshots do not say what is actually reachable in the viewport, causing wasted layout debugging and invalid tests.
- secret-finding-triage — reviewers need scanner context without spreading the secret-adjacent source they are trying to protect.
- trace-context-probe — richer tracing is useless when async boundaries silently break parentage.
- telemetry-export-receipts — small self-hosted stacks need an accountable data-egress boundary, not merely ingestion controls.
- alert-evidence-envelope — on-call and automation need a bounded incident excerpt rather than a dashboard link and more credentials.
- data-change-impact-card — mutable schema and observed data changes still leave operators guessing which derived assets are stale.
- firebase-environment-doctor — terminal-first Firebase work needs a trustworthy read-only preflight before debugging or changing the wrong project.
