# Installables research — 2026-08-28

family-archive-check — families need proof that their irreplaceable media is recoverable, not another gallery.
sideload-readiness — Android policy churn makes a safe, explainable local install-readiness check timely.
opds-shelf-bridge — open-reader stacks still fail at the seams between catalog, credentials, formats, and devices.
vram-fieldtest — expensive used GPUs lack a cross-vendor, coverage-explicit memory test report.
sleep-watt-watch — idle power drain remains difficult to attribute after the machine wakes or sleeps badly.
freeze-capsule — Linux freezes erase the context needed for a useful bug report.
mail-escape-hatch — provider exit needs a verified, portable mail archive rather than a client-specific export.
offline-file-bridge — an app's offline cache is often inaccessible to the local apps users need next.
android-compat-scout — customized Android setups regress across OS, permission, and accessory changes.
terminal-recall — terminal/TUI output is valuable evidence but current retention is fragmented and unsafe.
legacy-app-rescue — users need to preserve their own legacy mobile software without risky APK hunting.
cloud-exit-drill — a cloud export is not a backup until a local restore has been rehearsed.
