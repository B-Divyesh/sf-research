# Utilities research — 2026-08-27

bank-csv-intake-check — Bank imports still fail silently; a local preflight can catch loss before it reaches a ledger.

payout-reconciliation-casefile — Ecommerce operators need source-file evidence for payout mismatches, not another bookkeeping suite.

availability-dst-audit — DST can publish bookable hours the organizer never intended; fixture-based auditing is a small, vendor-neutral fix.

rename-plan-reviewer — Spreadsheet and regex bulk renames need a reversible plan before they touch irreplaceable files.

file-change-space-check — File operations make space decisions before conflict policy is known; simulate the outcome first.

notes-import-preflight — Large note migrations still fail or lose attachments; inventory fidelity before committing to an import.

identity-migration-map — Identifier renames fan out across apps and data; an offline dependency map makes the handoff reviewable.

knowledge-handoff-bundle — Teams lose context and links at ownership changes; a static verified handoff bundle keeps the current state inspectable.

passkey-extension-check — Co-installed password extensions can block passkeys; users need a no-secret compatibility check before lockout.

document-integrity-receipt — Edited PDFs can retain confusing signature metadata; recipients need a clear local provenance receipt.

a11y-interaction-trace — Keyboard/focus failures are hard to communicate; local traces join the interaction with a11y state.

remote-file-handoff-manifest — Private file delivery needs a recipient-verifiable manifest independent of the transfer product.
