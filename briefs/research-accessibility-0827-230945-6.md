# Accessibility opportunity research — 2026-08-27

workspace-reflow — low-vision workers need selected live app regions reflowed, not only magnified or screen-read.

caption-confidence — caption users need uncertainty and sound-confusion cues instead of repeated replay.

thought-parking — ADHD idea capture needs to defer organization so it does not become another interruption.

meeting-recall-markers — private decision/action anchors can support meeting recall without recording everyone.

dyslexia-reading-resume — sentence-level return points address interruption loss beyond font and TTS controls.

color-status-labeler — users need live dashboards to expose status redundantly, not a designer-only color simulation.

no-bot-captions — real-time private captions remain valuable where meeting bots cannot be invited.

proper-noun-lexicon — local, reversible terminology correction tackles the high-cost name errors in dictation.

quiet-dictation-bridge — a close-mic phone-to-desktop path makes push-to-talk viable in shared workspaces.

pronunciation-cards — portable pronunciation metadata can make technical audio reading more dependable.

reading-comfort-pacer — break prompts are more usable when they wait for a reading boundary.

hearing-mode-notes — hearing-aid settings are situational, while existing control apps do not preserve what worked by place.
