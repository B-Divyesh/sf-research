# Education research — 2026-08-28

answer-anchored-flashcards — learners want recall scheduling grounded in an answer, not a vague self-rating.

video-code-exit-tickets — interactive code lessons are proven, but a portable checkpoint layer is still missing.

promptless-ml-lab — self-taught ML learners explicitly want standardized, reproducible practice with quick feedback.

solution-trace-practice — AI-assisted beginners need a lightweight way to retain diagnosis and debugging practice.

proof-study-pacts — Lean learners ask for structured study groups rather than another set of tutorials.

learner-evidence-map — self-directed learning needs a compact link between a claim, practice, and evidence.

math-prerequisite-sketch — adults returning to math need local prerequisite repair, not wholesale curriculum restarts.

workload-reschedule-receipts — students need honest recovery plans after a missed work block, not idealized scheduling.

context-vocabulary-capture — context-preserving, low-friction capture is a repeated language-reading pain.

pronunciation-contrast-log — recognition and spoken production diverge; learners need a privacy-first contrast practice log.

assessment-authorship-receipts — educators need humane process evidence without AI detection or surveillance.

music-practice-stability — musicians need repeatability feedback beyond speed, note accuracy, and gamified scores.
