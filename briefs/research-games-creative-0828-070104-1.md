# Games & creative research — 2026-08-28

transposing-sketchpad — novice composers need an audible way to learn sounding versus written pitch without a full notation suite.

midi-roundtrip-check — export fidelity remains opaque when a score becomes a hardware/DAW MIDI file.

flipbook-proof — physical flipbook makers need a local, printable frame plan before investing days of tracing.

lesson-motion-cues — educators need code-readable animation cues without inheriting a game engine’s timing complexity.

animatic-event-strip — small teams need portable visual/audio event planning before implementation binds animations to code.

life-lab-notebook — cellular-automata exploration is popular but lacks reproducible, shareable experiment records.

inclusive-game-jam-cards — families need a first-game path that starts with mechanics and accessibility, not editor setup.

daily-range-puzzle — there is demand for daily browser games and a neglected opportunity for shared map-distance reasoning.

score-aligned-choir-cleanup — choirs with scores and poor archives need conservative, local rehearsal-copy cleanup.

sound-pattern-playground — on-device audio learners need feature-level visual feedback instead of a black-box model demo.

generative-palette-a11y — generative artists need color-accessibility feedback that respects animation and palette intent.

local-sketch-deck — creative learners still lack a current, local draw-and-behave environment between Scratch and full web development.
